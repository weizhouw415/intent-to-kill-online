# 暗藏杀机 · 双人对战

基于《Intent to Kill／暗藏杀机》**双人逻辑模式**制作的浏览器桌游。一人扮演凶手，一人扮演侦探；支持同一台电脑轮流操作，也支持两台电脑用房间码联机对战。

## 本机启动

需要 Node.js 20 或更新版本，无需安装第三方依赖。

```bash
cd /Users/weizhouw/workspace/codex-work/intent-to-kill-online
npm start
```

打开 `http://localhost:3187`，然后选择对战方式。

### 同一台电脑

点击“开始同机双人对战”。凶手先选择支持者群体，然后系统自动遮住棋盘，交给侦探选择起点。此后每次换人、以及每次讯问需要凶手作答时，都会出现交接屏；接手的玩家点击确认后才会看到自己的视角。顶部“遮挡屏幕”可随时暂时隐藏当前画面。双方笔记按角色分开保存在浏览器中。

### 两台电脑联机

第一位玩家选择凶手或侦探，创建房间并复制邀请链接。第二位玩家打开相同服务器地址，输入六位房间码加入。浏览器刷新后会自动恢复自己的玩家身份。

#### 同一局域网

在运行服务器的电脑上找到局域网 IP 地址（例如 `192.168.1.20`），第二台电脑打开 `http://192.168.1.20:3187`。服务器默认监听 `0.0.0.0:3187`，可能需要允许 Node.js 通过系统防火墙。

#### 跨互联网

把此目录部署到能运行 Node.js 的服务器。设置 `PORT` 为服务商分配的端口、`PUBLIC_URL` 为实际 HTTPS 访问地址，并通过该地址访问。建议为 `DATA_FILE` 指定持久目录，例如 `/data/rooms.json`，否则部署平台重启后对局可能丢失。房间码用于加入，玩家令牌存储在各自浏览器中；请只分享房间码，不要分享浏览器开发者工具里的令牌。

可用 Docker 构建：

```bash
docker build -t intent-to-kill-online .
docker run -d --name intent-to-kill -p 3187:3187 -v itk-data:/data -e DATA_FILE=/data/rooms.json intent-to-kill-online
```

互联网部署时在 Docker 前配置 HTTPS 反向代理。

## 当前实现

- 20 名市民从 54 张人物档案中随机抽取；四项外貌特征均衡且组合唯一。
- 凶手秘密身份、相关人、真实动机、支持者群体；侦探端不会收到这些字段。
- 六种入门动机、每回合两次恐吓、合法谋杀校验、一次放弃机会。
- 现场疏散、侦探两点移动、两种不同调查行动、讯问与允许说谎的证人、警局监视、餐馆、医院、消防局。
- 城市阶段的群体抽取与市民移动；第五起命案后同时指认凶手与动机。
- 同机交接遮挡、按角色分开的本地笔记；联机实时同步；刷新恢复与服务器磁盘存档。

范围：目前提供**逻辑模式**。直觉模式的行动牌、证据标记与扩展剧本尚未制作。棋盘插画和人物卡为本项目原创图形，首页盒面照片来自用户提供的实物照片；没有复制原版人物插画或卡面。
